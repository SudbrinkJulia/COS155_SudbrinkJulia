This week I added three features to E.M.O.S. First, I added color to the console so the title, menu, headings, and results are easier to notice. Second, I added a reset option that returns stability, empathy, fear, and curiosity to 50. Third, I added a session summary that shows how many stimuli, emotional cycles, and diagnostics have happened, along with the current Ascension Score.

I followed my feature plan by working on each feature separately in its own branch. I kept the code straightforward: the emotion engine handles resetting the emotional values, SystemCore tracks the action counts and displays the summary, and the menu and main program let the user choose the new options. One challenge was updating the menu numbers and the matching choices in the main program so they stayed in sync. I built and ran the program, then checked that resetting returned the values to 50 and that the summary showed the correct counts and score.

These features make E.M.O.S. easier to use and give the user more feedback about what the program is doing. If I had more time, I would improve the session summary by tracking additional actions, such as how many Ascension Trials were run. I would also keep testing invalid menu input and different action sequences as I add more features.
